# 📦 Entregables

Aquí se guarda **la versión final** de lo que se sube a la plataforma en cada corte,
ya exportada en PDF y lista para calificar.

## Reglas

1. Un archivo por entregable, nombrado `corteN-nombre-entregable.pdf`.
2. **Nunca se sobreescribe** un entregable ya enviado. Si hay correcciones, se sube una
   versión nueva: `corte1-documento-vision-v2.pdf`.
3. El material de trabajo (borradores, archivos editables) vive en las demás carpetas;
   aquí solo llega el resultado final.
4. Registra cada entrega en la tabla de abajo y en el README principal.
